SmartODL updated source bundle — Windows local update

IMPORTANT
- This source bundle excludes local .env files, node_modules, uploads and your database.
- Back up F:\Project\smartodl, backend\.env, backend\uploads and the database before copying source.
- This bundle does not modify F:\Project\smartodl directly.

Update steps (PowerShell)
1. Stop backend/frontend processes (Ctrl+C) and make a backup of F:\Project\smartodl.
2. Extract this ZIP to a temporary folder.
3. Copy the extracted Smartodl source contents over F:\Project\smartodl. Do not overwrite your .env or uploads; the bundle excludes them.
4. Backend terminal:
   cd F:\Project\smartodl\backend
   npm ci
   npm run migrate
   npm start
5. Frontend terminal:
   cd F:\Project\smartodl\frontend
   npm ci
   npm run dev

17. LESSON COMPLETE KA NAYA RULE (watch-lock + quiz gate): pehle student lesson khol ke 15 second baad 'Mark complete' daba deta tha, video dekha ya nahi koi check nahi tha. Ab har course me rule chun sakte hain — Admin/Courses > course edit > 'Lesson complete karne ka rule': (a) 'Open + time (default)' = purana behaviour, kuch nahi badlega; (b) 'Video 90% dekhna zaroori' = uploaded video ka 90% timeline chalna chahiye; (c) 'Linked quiz pass karna zaroori' = course ka linked quiz pass hona chahiye; (d) 'Video 90% + quiz pass' = dono. Coverage 10-second slices se naapi jaati hai: seek karke end tak kheenchne se sirf 1 slice count hota hai (test me seek-to-end = 50%, honest playback = 100%), paused tab count nahi hota, 2x speed allowed, 10x fast-forward nahi. YouTube/Vimeo link naapa nahi ja sakta (cross-origin) isliye wahan watch requirement apne aap skip ho jaati hai — video upload karein to coverage banti hai. Pehle se bane completions/certificates par koi asar nahi. Details: docs\COMPLETION-POLICY.md
18. Naye lesson-watch endpoints: POST /api/lessons/:id/watch (player heartbeat), GET /api/lessons/:id/watch (coverage status). Schema: 'npm run migrate' courses.completion_policy + lesson_watch + lesson_watch_buckets banata hai; manual ke liye database\patch-lesson-watch.sql (dobara chalane par kuch nahi bigadta). Note: agar aap chaahte hain ki galti se bhi koi bina dekhe complete na kar sake, to course policy 'Video 90% + quiz pass' rakhein — sirf watch-lock script se bypass ho sakta hai, quiz se marks nahi.
